triplets.iri package¶

The triplet ↔ IRI contract — one definition for ID, KEY and VALUE.

Instance data in a triplet frame is stored local: bare IDs, Class.attr KEYs, local-name VALUEs (W3C: local name). RDF serializations (N-Quads, SPARQL stores, SHACL reports) are absolute: absolute IRIs. This package owns both directions.

ID, INSTANCE_ID, focus, graph

VALUE

namespace + local name of any IRI

split_iri

—

One split, split_iri(), underlies every name. Two policies sit on top: a name (KEY, class, enum value) always drops its namespace — the schema restores it; a node (ID, reference) drops only what a convention restores (local_id(): urn:uuid:, #_, _) and otherwise stays whole. The local form is for people working on imported data; where local names collide (type is both rdf:type and dcterms:type), only the absolute form is exact.

Local rules are schema-free (a parse has no schema). Absolute rules take the flat maps built from the export schema — namespaces(), value_types(), datatypes(), languages(), prefixes(), one dict each, only the ones a call site needs. The schema entry type decides the serialisation form (Attribute → literal, Association → reference, Enumeration → enum IRI); xsd:type only annotates literals — any prefixed name or IRI, expanded by the schema’s ProfileNamespaceMap — and language tags them instead (a tagged literal has no datatype annotation). A name the schema does not declare — every name without a schema — takes undefined_namespace (http://triplets# unless the caller says otherwise).

Flavors: triplets.iri.iri_pandas, triplets.iri.iri_polars and triplets.iri.iri_duckdb implement the same names over Series / Expr / SQL text. The cython parser and the qlever C++ ingest mirror the same rules natively. All of them are held to one case table in tests/test_iri.py — the scalar functions here are the readable definition, the table is the contract.

This module imports only the standard library: the parser imports it on every file.

triplets.iri.TYPE_KEY = 'Type'¶

KEY of the typed-node element name — the one type CIM XML writes as the object element.

triplets.iri.DESCRIPTION_TYPE = 'Description'¶

no typed-node shorthand, so not a class — exported as rdf:Description in CIM XML and as no rdf:type in N-Quads.

Type:

Type VALUE of an rdf:Description element

triplets.iri.UUID_RE = re.compile('^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$')¶

Canonical lowercase mRID — absolute_value() reads such a VALUE of a KEY the schema does not define as a reference.

triplets.iri.REFERENCE_LIKE = re.compile('(?:[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}|\\w+://\\S+|urn:\\S+|[A-Za-z]\\w*\\.\\w+)$')¶

Loose “looks like a reference” heuristic for SHACL nodeKind when the schema says nothing about a key. Not the RDF term rule — absolute_value() uses UUID_RE.

triplets.iri.LANGUAGE_TAG_RE = re.compile('^[A-Za-z]{1,8}(?:-[A-Za-z0-9]{1,8})*$')¶

BCP 47 language tag well-formedness (en, en-GB) — the shape languages() accepts.

triplets.iri.IRI_UNSAFE = '\x00\x01\x02\x03\x04\x05\x06\x07\x08\t\n\x0b\x0c\r\x0e\x0f\x10\x11\x12\x13\x14\x15\x16\x17\x18\x19\x1a\x1b\x1c\x1d\x1e\x1f <>"{}|^`\\'¶

Characters an N-Triples / SPARQL IRIREF may not hold (controls, space, <>"{}|^`\).

triplets.iri.local_id(text)[source]¶

urn:uuid:x / #_x / _x → x. One prefix, longest first. None → None.

triplets.iri.split_iri(iri)[source]¶

IRI → (namespace, local name), lossless (namespace + local == iri): cut after the last # or /, else after a urn:’s last :; neither → ("", iri). None → (None, None). The one split every name rule uses (flavors: SPLIT_RE).

The CIM XML parsers get KEY and Type VALUE from element tags, where XML has already split the QName (lxml {ns}local, pugixml prefix:local); this is the same split for an IRI string — an XML local name holds neither # nor /.

triplets.iri.local_key(iri, type_key='Type')[source]¶

Predicate → KEY: rdf:type → type_key, else the split_iri() local name.

triplets.iri.VALUE_KINDS = ('class', 'enum', 'reference')¶

class (a Type VALUE) and enum are names, reference a node; None guesses without a schema.

Type:

local_value kinds

triplets.iri.local_value(iri, kind=None)[source]¶

VALUE IRI → local VALUE by kind:

  • "class" / "enum" → a name: the split_iri() local name.

  • "reference" → a node: local_id() (other namespaces stay whole).

  • None — no schema, guess: local_id(), then an http(s) IRI with a # is taken as a name (enum / class: Kind.value, its split_iri() local name); anything else stays whole (/-only IRIs are external references, a namespace IRI ending in # or / has no name). None → None.

triplets.iri.is_iri(text)[source]¶

Absolute IRI already (http://, https://, urn:).

triplets.iri.is_absolute(text)[source]¶

Absolute for resolution and the RDFS tools: is_iri(), or any scheme:// IRI (file:// too). A prefixed name (cim:Foo) or M:1..1 is not.

triplets.iri.resolve_iri(reference, base)[source]¶

RDF/XML reference → absolute IRI against base (xml:base, else the document URI), RFC 3986: an absolute IRI passes through, #frag / "" → base without its fragment + reference, else a relative-path join. No base → unchanged. None → None.

triplets.iri.encode_iri(text)[source]¶

Percent-encode the characters an IRI may not hold, so a schema reference / enum value stays an IRI whatever its text (a b → a%20b). None → None.

triplets.iri.decode_iri(text)[source]¶

Inverse of encode_iri() for IRI terms read back from RDF — only those escapes. None → None.

triplets.iri.load_rdf_map(rdf_map)[source]¶

Export schema: dict or JSON path → dict. None → {}.

triplets.iri.load_schema(rdf_map)[source]¶

dict or path → (schema dict, content digest, source name) — for compile caches keyed on content.

triplets.iri.rdf_map_entries(rdf_map)[source]¶

Every (name, entry) of the schema: the root entries, then each profile section’s in schema order — reversed so a dict comprehension over it keeps the FIRST (a dict keeps the last write). A name both the root and a section define takes the root entry: the root is what validation reads by default (rdf_map_scope=None).

triplets.iri.namespaces(rdf_map)[source]¶

name → namespace IRI, every entry (classes, keys, enum values, datatypes).

triplets.iri.key_types(rdf_map)[source]¶

name → schema entry type (Class | Attribute | Association | Enumeration | EnumerationValue | …).

triplets.iri.prefixes(rdf_map)[source]¶

prefix → namespace IRI from every ProfileNamespaceMap (the root’s, then each profile section’s in schema order; first binding wins); xsd, rdf and rdfs are built in where no map binds them — a bundle need not declare xsd.

triplets.iri.absolute_datatype(key, text, prefixes)[source]¶

key’s xsd:type text → datatype IRI: an absolute IRI passes through, prefix:local → the prefix’s namespace + local. A text without a prefix, or with one prefixes does not bind, raises ValueError naming key — the schema is configuration, so a typo fails loudly instead of leaving the key untyped.

triplets.iri.datatypes(rdf_map)[source]¶

KEY → datatype IRI for Attribute entries with an xsd:type (any prefixed name or IRI, expanded by prefixes()); None = plain literal (xsd:string, rdf:langString, hence every KEY languages() tags — built here too, so its ValueError fires wherever this map is built). Annotation / validation only — it never decides whether a value is a literal or an IRI.

triplets.iri.language_tag(key, tag, declared, prefixes)[source]¶

key’s language → the tag: a well-formed BCP 47 tag on a KEY whose xsd:type declared is empty or a plain literal (xsd:string, rdf:langString), else ValueError naming key — a language-tagged literal has no other datatype.

triplets.iri.languages(rdf_map)[source]¶

KEY → language tag, from the first Attribute entry of the KEY that carries a language; checked by language_tag() against the KEY’s xsd:type as datatypes() resolves it (first entry with one). The literal is written "text"@tag (N-Quads) / xml:lang="tag" (CIM XML), with no datatype annotation.

triplets.iri.value_types(rdf_map)[source]¶

KEY → "literal" | "reference" | "enum" by schema entry type; absent = undefined KEY.

triplets.iri.absolute_id(text)[source]¶

Bare ID / INSTANCE_ID → urn:uuid:…; an absolute IRI passes through; then encode_iri(). None → None.

triplets.iri.absolute_name(name, namespaces=None, undefined_namespace='http://triplets#')[source]¶

Local schema name (class, enum value, key) → its namespace + name; an undeclared name takes undefined_namespace; IRIs / None pass through.

triplets.iri.absolute_key(key, namespaces=None, undefined_namespace='http://triplets#')[source]¶

KEY → predicate IRI: Type → rdf:type, else absolute_name().

triplets.iri.defined(key, value, namespaces=None, value_types=None)[source]¶

Does the schema account for this row? Type → the class is declared; else the KEY is declared and, for an enum KEY, so is the value. Without a schema nothing is defined.

triplets.iri.absolute_value(key, value, namespaces=None, value_types=None, datatypes=None, undefined_namespace='http://triplets#')[source]¶

VALUE → ("iri", iri) or ("literal", datatype_iri_or_None).

Type → class IRI. Otherwise the schema entry type of the KEY decides, never the shape of the text: enum → enum IRI, reference → absolute_id() of the value (absolute passes through, else urn:uuid:), literal → datatype annotation (an Attribute stays a literal even when its text looks like an IRI or a UUID). An undefined KEY falls to the shape heuristic: absolute IRI or canonical UUID → reference, else plain literal. Quoting and escaping belong to the serializer, not here.

triplets.iri.node_kind(key, value_types)[source]¶

sh:nodeKind by schema entry type, the same rule the exporters apply: Association / Enumeration → "iri", Attribute → "literal"; None (undefined KEY) → check the value form.

triplets.iri.iri_pandas¶

pandas flavor of triplets.iri — Series in, Series out, same names.

Nulls propagate (None/NaN in → None/NaN out) except where a rule needs a boolean, which treats null as “no” (na=False, never fillna — that downcast is deprecated on object columns).

triplets.iri.iri_pandas.split_iri(series)[source]¶

→ (namespace, local) Series; namespace “” where there is no delimiter.

triplets.iri.iri_pandas.local_id(series)[source]¶
triplets.iri.iri_pandas.local_key(series, type_key='Type')[source]¶
triplets.iri.iri_pandas.by_distinct(series, rule)[source]¶

rule applied once per distinct value — dictionary-encode, apply, take — for low-cardinality columns (KEY, INSTANCE_ID, class / enum names). Returns arrow-backed strings; nulls stay null.

triplets.iri.iri_pandas.local_value(series, kind=None)[source]¶

kind: None (guess), one of VALUE_KINDS for every row, or a Series of them per row.

triplets.iri.iri_pandas.is_iri(series)[source]¶
triplets.iri.iri_pandas.encode_iri(series)[source]¶
triplets.iri.iri_pandas.decode_iri(series)[source]¶
triplets.iri.iri_pandas.absolute_id(series)[source]¶
triplets.iri.iri_pandas.absolute_name(series, namespaces=None, undefined_namespace='http://triplets#')[source]¶
triplets.iri.iri_pandas.absolute_key(series, namespaces=None, undefined_namespace='http://triplets#')[source]¶
triplets.iri.iri_pandas.defined(key, value, namespaces=None, value_types=None)[source]¶

Boolean mask of rows the schema accounts for — see the scalar rule.

triplets.iri.iri_pandas.absolute_value(key, value, namespaces=None, value_types=None, datatypes=None, undefined_namespace='http://triplets#')[source]¶

→ (kind, payload) Series: kind ∈ {“iri”, “literal”}; payload is the IRI, or the xsd datatype IRI / null for literals. Same precedence as the scalar rule, applied as masks from lowest to highest — stays in the string dtype (no object arrays).

triplets.iri.iri_polars¶

polars flavor of triplets.iri — column name or Expr in, Expr out, same names.

Pure expressions, no Python UDFs. Columns are expected as Utf8 (cast Categorical first, as the N-Quads exporter does).

triplets.iri.iri_polars.split_iri(column)[source]¶

→ (namespace, local) Exprs; namespace “” where there is no delimiter.

triplets.iri.iri_polars.local_value(column, kind=None)[source]¶

kind: None (guess), one of VALUE_KINDS for every row, or an Expr of them per row.

triplets.iri.iri_polars.is_iri(column)[source]¶
triplets.iri.iri_polars.encode_iri(column)[source]¶
triplets.iri.iri_polars.decode_iri(column)[source]¶
triplets.iri.iri_polars.absolute_id(column)[source]¶

triplets.iri.iri_polars.defined(key, value, namespaces=None, value_types=None)[source]¶

Boolean Expr of rows the schema accounts for — see the scalar rule.

triplets.iri.iri_polars.absolute_value(key, value, namespaces=None, value_types=None, datatypes=None, undefined_namespace='http://triplets#')[source]¶

triplets.iri.iri_duckdb¶

duckdb flavor of triplets.iri — SQL expression text in, SQL expression text out, same names.

Only the names the duckdb SHACL engine uses; each is held to tests/test_iri.py like the other flavors.

triplets.iri.iri_duckdb.local_value(column, kind=None)[source]¶
